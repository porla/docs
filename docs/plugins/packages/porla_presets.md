# `porla_presets`

Allows getting presets.

## Exports

### <code>default(): [PoPreset](../types/popreset.md)?</code>

<Since>v1.0</Since>

Returns the default preset (if any), or `nil`.

### <code>get(id: number): [PoPreset](../types/popreset.md)?</code>

<Since>v1.0</Since>

Returns a preset by ID, or `nil`.

### <code>get(name: string): [PoPreset](../types/popreset.md)?</code>

<Since>v1.0</Since>

Returns a preset by name, or `nil`.
