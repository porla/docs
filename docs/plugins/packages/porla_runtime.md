# `porla_runtime`

Exports information about the runtime, such as which plugin API version is
currently available.

Plugins can use these to check which methods and properties are available on
types and packages.

## Exports

### `api_version_major: number`

<Since>v0.42.0</Since>

The major plugin API version.

### `api_version_minor: number`

<Since>v0.42.0</Since>

The minor plugin API version.

### `args["state-dir"]: string`

### `args["http-base-path"]: string`

### `version: string`

<Since>v0.46.0</Since>
