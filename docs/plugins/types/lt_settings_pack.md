# `lt.settings_pack`

The `settings_pack` can be used to update session settings.

## Factories

### `default`

```lua
local default_settings = lt.default()
```

### `high_performance_seed`

```lua
local high_perf_seed_settings = lt.high_performance_seed()
```

### `min_memory_usage`

```lua
local min_mem_usage_settings = lt.min_memory_usage()
```
