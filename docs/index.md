# Porla

Porla is a powerful BitTorrent client with high performance and low memory
usage. It is designed for headless operations on servers and seedboxes and can
easily manage tens of thousands of torrents.

It is based on [Rasterbar-libtorrent](https://libtorrent.org) and tries to stay
close to the libtorrent APIs in most cases.

## Features

 * Multi-session support to run isolated libtorrent sessions makes it easy to
   try session settings on a subset of torrents.
 * Use [Lua](https://www.lua.org/) to write plugins.
