# `sessions.list`

Lists all sessions. Also includes their metadata and torrents count.

## Request

```json
{}
```

## Response

```json
{
  "sessions": [
    {
      "id": 8,
      "name": "long-term-seed",
      "metadata": {
        "$color": "#ff00ff"
      },
      "torrents_total": 544
    }
  ]
}
```
